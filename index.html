01 — Tentang

Kenalan lebih dekat

Sedikit cerita tentang siapa saya dan apa yang saya kerjakan.

Saya Muhammad Faris, seorang Web Developer muda yang berbasis di Bogor, Indonesia. Saat ini saya menempuh pendidikan di SMK jurusan PPLG (Pengembangan Perangkat Lunak dan Gim), di mana saya terus mengasah kemampuan dalam membangun aplikasi web dan mobile yang fungsional serta menarik.

Saya percaya bahwa belajar adalah proses seumur hidup. Dengan semangat "Pelajar Seumur Hidup", saya aktif mengeksplorasi berbagai teknologi — mulai dari HTML, CSS, dan JavaScript untuk web development, Flutter untuk mobile apps, hingga Figma untuk desain UI/UX.

Saya senang mengubah ide menjadi kenyataan melalui kode, dan selalu antusias untuk berkolaborasi dalam proyek-proyek yang menantang! 🚀
